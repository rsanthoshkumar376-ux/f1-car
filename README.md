# Formula Algorithmic: Spectral Racer

![Branding](https://img.shields.io/badge/Algorithm-Pure-blueviolet?style=for-the-badge&logo=formula1)
![Physics](https://img.shields.io/badge/Physics-Deterministic-brightgreen?style=for-the-badge)

**Formula Algorithmic** is a 100% seed-based, deterministic racing simulation. Every chassis, track sector, and sound wave is procedurally generated from a single mathematical Master Seed.

## 🧬 Core Algorithmic Features

*   **Generative F1 Chassis**: Every car in the infinite garage is a procedural construct. Their Speed, Stability, and Aerodynamic silhouettes are calculated mathematically.
*   **Spectral Determinism**: The world is 100% reproducible. Share a Master Seed, and every player will experience the exact same track layout and obstacle sequence.
*   **Pure Math Synthesis**: All audio interactions are synthesized in real-time. Melodies and engine drones evolve based on the velocity vectors and entropy of the run.
*   **Chaos Theory Scoring**: Features an **Entropy Meter** that measures the mathematical complexity of your maneuvers (stunts, air-time, and high-speed variance).

## 🏁 How to Run

1.  Clone the repository.
2.  Open `index.html` in any modern web browser.
3.  **INITIALIZE DRIVE** to begin the sectoral decryption sequence.

## 🛠️ Tech Stack
- **Physics**: Matter.js
- **Rendering**: HTML5 Canvas (2D) & Three.js (3D Menu)
- **RNG**: Mulberry32 (Custom Seedable PRNG)
- **Audio**: Web Audio API (Synthesized)
